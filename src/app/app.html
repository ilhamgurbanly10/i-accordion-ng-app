Angular Accordion package by Ilham Gurbanly

Visit package on npm

Documentation:

  • data: (Required) - array of objects.
  • title: string (Required) - title of accordion item
  • description: string (Optional) - content of accordion item
  • key: string | number (Required) - unique key of accordion item
  • disabled: boolean (Optional) - whether accordion item is disabled
  • activeInitially: boolean (Optional) - whether accordion item is active initially
  • options: (Optional) - options object.
  • showMultiple: boolean (Optional) - whether multiple items can be shown at the same time, default value is true
  • titleVariant: html | text (Optional) - whether to render title as HTML or text, default value is html
  • descriptionVariant: html | text (Optional) - whether to render description as HTML or text, default value is html
  • headIsClickable: boolean (Optional) - whether the head itself is clickable or only the plus/minus button, default value is true
  • headColors: colors object (Optional) - defines the head colors for active, deactive, and disabled states
  • bg: string (Optional) - background color
  • text: string (Optional) - text color
  • descriptionColors: colors object (Optional) - defines the head colors for active and disabled states
  • bg: string (Optional) - background color
  • text: string (Optional) - text color
